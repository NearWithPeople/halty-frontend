# Интерактивное веб-приложение карт Mapbox

Полнофункциональное современное веб-приложение со стандартным интерфейсом навигационных карт (в стиле Apple Maps / Google Maps) на базе библиотеки **Mapbox GL JS**, **React**, **TypeScript** и **Tailwind CSS**.

---

## 🚀 Основные возможности

### 1. 🔍 Интеллектуальный поиск и категории
- **Строка поиска** с автодополнением и геокодированием через Mapbox Geocoding API (с поддержкой OpenStreetMap Nominatim в качестве резервного источника).
- **Быстрые категории в 1 клик**: Кафе, Рестораны, Заправки, Отели, Достопримечательности, Парки.
- Плавный перелёт (`flyTo`) к выбранному адресу или объекту с установкой маркера.

### 2. 🗺️ Переключение слоев и стилей карты
- **Схема (Streets-v12)** — классическая детализированная векторная карта.
- **Спутник (Satellite Streets)** — спутниковые снимки высокого разрешения с наложением дорог.
- **Топография (Outdoors-v12)** — карта с рельефом и высотами для активного отдыха.
- **Тёмная тема (Dark-v11)** — контрастный ночной режим.
- **Светлая тема (Light-v11)** — лаконичный минималистичный стиль.
- **Навигатор (Day / Night)** — специализированные стили для автомобильной навигации.

### 3. 🏢 3D-режим и 3D-здания
- Поддержка переключения между **2D** (вид сверху) и **3D** (наклон камеры 60°).
- Интерактивный слой **3D-зданий** с экструзией и реалистичной высотой сооружений.
- Живой компас с индикацией угла поворота карты и сбросом ориентации на север.

### 4. 🧭 Построение маршрутов (Directions)
- Выбор начальной точки («Моё местоположение» или клик по карте) и пункта назначения.
- Режимы передвижения:
  - 🚗 Автомобиль (`driving`)
  - 🚶 Пешком (`walking`)
  - 🚲 Велосипед (`cycling`)
- Расчёт оптимального пути через Mapbox Directions API.
- Отображение длины маршрута (км), расчётного времени и пошаговых указаний (turn-by-turn).

### 5. 📍 Карточка выбранного места и закладки
- При клике на любое место отображается карточка с названием, точным адресом и координатами.
- Кнопка быстрого копирования координат в буфер обмена.
- Возможность сохранения мест в **«Избранное»** (сохраняются локально в `localStorage`).
- Быстрый переход к маршруту до выбранной точки.

### 6. 📏 Инструмент измерения расстояний (Линейка)
- Клик по точкам на карте для замера прямой или ломаной линии.
- Автоматический расчёт суммарного расстояния в метрах и километрах по формуле гаверсинусов.

### 7. 🔑 Управление ключом Mapbox (Access Token & .env)
- Поддержка переменной окружения в `.env` файле: `VITE_MAPBOX_ACCESS_TOKEN`.
- Встроенное модальное окно для ввода или обновления токена прямо в интерфейсе (сохраняется в `localStorage`).
- Поставляется с готовым демо-токеном «из коробки».

### 8. 🌫️ Премиальный визуальный эффект GradualBlur (React Bits)
- Интегрирован компонент **`<GradualBlur />`** с градиентным размытием краёв (Apple Maps стиль) сверху и снизу карты.
- Обеспечивает мягкий переход между интерактивной картой, строкой поиска и панелью статуса.

---

## ⚙️ Настройка окружения (.env)

Создайте файл `.env` в корне проекта (шаблон есть в `.env.example`):
```env
VITE_MAPBOX_ACCESS_TOKEN=pk.eyJ1...
```

---

## 🛠️ Запуск проекта

### Режим разработки:
```bash
npm run dev
```
Сервер запустится по адресу: **http://localhost:5173/**

### Сборка для продакшена:
```bash
npm run build
```
Файлы будут собраны в папку `dist/`.
